4. `py -3 -m pytest backend/tests -q` with ENVIRONMENT=test and isolated DB overrides before import, provider keys empty.
5. PostgreSQL migration/auth/config integration suite (scripts/tests added by T4; exact command recorded with result).
6. Browser smoke student+Admin real DB, including config local stub; UI fault cases separate.
7. Source manifest comparison before/after gate; only report/log/test artifacts excluded.
